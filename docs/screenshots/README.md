# Screenshots

Capture screenshots from the running app and save them here for the competition submission.

## Required Screenshots

| File | Screen | How to Capture |
|------|--------|----------------|
| `01-dashboard.png` | Full dashboard overview | Open app → default room → full-page screenshot |
| `02-spin-wheel.png` | Spin wheel mid-animation | Select chore → click Spin → screenshot during animation |
| `03-leaderboard.png` | Leaderboard with points | Scroll to leaderboard section |
| `04-privilege-store.png` | Privilege Store | Open store section → screenshot |
| `05-trade-modal.png` | Trade modal | Click Trade on an assigned chore |
| `06-mobile.png` | Mobile responsive view | DevTools → toggle device toolbar → iPhone 14 |
| `07-onboarding.png` | Onboarding tutorial | Clear localStorage → reload → screenshot modal |
| `08-activity-feed.png` | Live activity feed | Complete a chore → screenshot notification feed |

## Tips

- Use 1920×1080 for desktop screenshots
- Use 390×844 for mobile screenshots
- Ensure the sketchbook UI is fully visible (no cropped elements)
- Run `npm run dev` before capturing

After adding screenshots, update the paths in `SUBMISSION.md` Section 9.
